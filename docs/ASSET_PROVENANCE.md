## Active-use decision

The first cinematic direction was rejected during visual review because the
abstract 3D gate and generated films did not explain the product. The current
page intentionally loads **no video, WebGL canvas, Three.js runtime, or 3D
model**. The `proof-artifact` component and Three.js dependencies were removed;
the generated files above remain versioned only as provenance for the rejected
exploration and are not referenced by the current interface or metadata.

The replacement visual system is authored from ProofRail's real states:
publication preview, claim underline, evidence relationship, human decision,
and publish gate. MotionSites member examples including Blog Showcase,
LaunchEx, NexaCore, Email Landing Page, and Urban Jungle were consulted through
the user's account for editorial scale, asymmetric composition, workflow logic,
and controlled transitions. No MotionSites prompt text, source code, hosted
media, or hotlinked asset is copied into this repository.
